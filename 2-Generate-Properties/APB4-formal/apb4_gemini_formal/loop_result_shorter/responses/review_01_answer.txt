REVIEW_FIX
The current formal harness has several issues that prevent it from correctly verifying the design according to the brief. The proposed changes will correct the scoreboard logic, improve the assertion timing to handle back-to-back transfers, and add a check for illegal read handling as specified.

### Review Audit and Proposed Fixes

1.  **Faulty Scoreboard Model:** The current model uses a single `known_data` bit for the entire 32-bit word. This is incorrect for verifying byte-lane behavior. If a single byte is written, the model considers the entire word "known," leading to spurious failures when comparing against `PRDATA`, as the other three bytes in `expected_data` are uninitialized.
    *   **FIX:** Replace `reg known_data` with `reg [3:0] known_bytes` to track the validity of each byte lane independently. The scoreboard will be updated to set the corresponding `known_bytes` bits based on `PSTRB` during a write.

2.  **Incorrect Data Integrity Assertion:** The assertion `assert(PRDATA == $past(expected_data))` compares the full 32-bit word. This is incorrect when only some bytes are known to be valid.
    *   **FIX:** The assertion will be changed to four separate per-byte comparisons, each guarded by its corresponding `known_bytes` bit. This correctly implements the requirement to only check known-valid data.

3.  **Incorrect Assertion Timing:** The assertion `if ($past(read_complete ...))` triggers one cycle *after* the read access completes. In a back-to-back read scenario, the slave updates `PRDATA` with data for the *next* transaction during this cycle. The original assertion would incorrectly compare data from the second read against the expected data from the first.
    *   **FIX:** The assertion trigger is moved to fire *during* the ACCESS phase (`if (read_complete ...)`). This ensures `PRDATA` for the correct transaction is sampled before it can be overwritten by a subsequent transfer, as required by the brief.

4.  **Overly-restrictive Assumption:** The assumption `if (!SWRITE) assume(SSTRB == 4'b0);` forces all read requests to be legal. This prevents the verification of the slave's error handling for illegal reads (where `PWRITE=0` and `PSTRB != 0`), a behavior explicitly mentioned in the design brief for checking.
    *   **FIX:** This assumption will be removed. A new assertion (`a_illegal_read_slverr`) is added to verify that the slave correctly asserts `PSLVERR` in response to a read request with non-zero strobes. The data integrity assertion is now correctly gated to apply only to *legal* reads (`PSTRB == 0`).

### Timing Table for Back-to-Back Reads (A then B) with Proposed Fix

This table shows how the corrected assertion (`if (read_complete) ...`) correctly handles a read of `AddrA` followed immediately by a read of `AddrB`. `watched_addr` is `AddrA`.

| Cycle | APB Phase         | `PADDR` | `PRDATA` (on bus)   | `read_complete` (for A) | Assertion `a_data_...` (for A) |
| :---- | :---------------- | :------ | :------------------ | :---------------------- | :------------------------------- |
| T0    | IDLE              | -       | -                   | 0                       | Not Triggered                    |
| T1    | SETUP A           | AddrA   | `X`                 | 0                       | Not Triggered. `PRDATA` latches `DataA` at end of cycle. |
| T2    | ACCESS A / SETUP B | AddrA   | `DataA`             | 1                       | **Fires & PASSES**. Compares `PRDATA` (`DataA`) with `expected_data` (`DataA`). `PRDATA` latches `DataB` at end of cycle. |
| T3    | ACCESS B          | AddrB   | `DataB`             | 0                       | Not Triggered for A.             |

The original checker would have fired at T3, comparing `PRDATA` (`DataB`) with the expected data for A, causing a false failure. The proposed fix checks at the correct time (T2).

module apb4_formal(input wire PCLK);
  // --- External System / Requester Driver ---
  (* anyseq *) reg transfer, SWRITE;
  (* anyseq *) reg [31:0] SADDR, SWDATA;
  (* anyseq *) reg [3:0] SSTRB;
  (* anyseq *) reg [2:0] SPROT;

  // --- Reset and History Generation ---
  reg first_cycle = 1'b1;
  reg past_valid = 1'b0;
  reg past_PRESETn = 1'b0;
  wire PRESETn = !first_cycle;

  always @(posedge PCLK) begin
    first_cycle <= 1'b0;
    past_valid <= 1'b1;
    past_PRESETn <= PRESETn;
  end

  // --- DUT Connections ---
  wire PSEL, PENABLE, PWRITE;
  wire [31:0] PADDR, PWDATA, PRDATA;
  wire [3:0] PSTRB;
  wire [2:0] PPROT;
  wire PREADY, PSLVERR;

  APB_Master Master (
      .PCLK(PCLK),
      .PRESETn(PRESETn),
      .SWRITE(SWRITE),
      .SADDR(SADDR),
      .SWDATA(SWDATA),
      .SSTRB(SSTRB),
      .SPROT(SPROT),
      .transfer(transfer),
      .PSEL(PSEL),
      .PENABLE(PENABLE),
      .PWRITE(PWRITE),
      .PADDR(PADDR),
      .PWDATA(PWDATA),
      .PSTRB(PSTRB),
      .PPROT(PPROT),
      .PREADY(PREADY),
      .PSLVERR(PSLVERR)
  );

  APB_Slave Slave (
      .PCLK(PCLK),
      .PRESETn(PRESETn),
      .PSEL(PSEL),
      .PENABLE(PENABLE),
      .PWRITE(PWRITE),
      .PADDR(PADDR),
      .PWDATA(PWDATA),
      .PSTRB(PSTRB),
      .PPROT(PPROT),
      .PREADY(PREADY),
      .PSLVERR(PSLVERR),
      .PRDATA(PRDATA)
  );

  // --- Requester Contract (Assumptions) ---
  always @(posedge PCLK) begin
    // Assume valid addresses are used for transfers after reset.
    if (PRESETn && transfer) begin
      assume(SADDR < 32'd1024);
    end
  end

  // --- Properties and Scoreboard ---
  (* anyconst *) reg [31:0] watched_addr;
  initial assume(watched_addr[31:10] == 22'b0); // Constrain to 0..1023

  reg [31:0] expected_data;
  reg [3:0]  known_bytes;

  wire is_setup   = PSEL && !PENABLE;
  wire is_access  = PSEL && PENABLE;
  wire write_complete = is_access && PWRITE && PREADY;
  wire read_complete  = is_access && !PWRITE && PREADY;
  wire at_watched_addr = (PADDR == watched_addr);
  
  reg saw_legal_read_setup_at_watched;

  always @(posedge PCLK) begin
    if (!PRESETn) begin
      known_bytes <= 4'b0;
      saw_legal_read_setup_at_watched <= 1'b0;
      // expected_data does not need reset, its validity is tracked by known_bytes
    end else begin
      // --- Helper flag for legal read setup ---
      saw_legal_read_setup_at_watched <= is_setup && !PWRITE && at_watched_addr && (PSTRB == 4'b0);

      // --- Scoreboard Update ---
      // Update on completed write to watched_addr. The model correctly preserves
      // un-strobed bytes, which the RTL is suspected of not doing.
      if (write_complete && at_watched_addr) begin
        if (PSTRB[0]) expected_data[7:0]   <= PWDATA[7:0];
        if (PSTRB[1]) expected_data[15:8]  <= PWDATA[15:8];
        if (PSTRB[2]) expected_data[23:16] <= PWDATA[23:16];
        if (PSTRB[3]) expected_data[31:24] <= PWDATA[31:24];
        known_bytes <= known_bytes | PSTRB;
      end

      // --- Data Integrity Assertion (Legal Read) ---
      // Check on the ACCESS cycle of a legal read to a watched address.
      if (read_complete && at_watched_addr && $past(saw_legal_read_setup_at_watched)) begin
        // Requirement: For a legal read, data from known-written bytes must match
        // the expected value from the scoreboard.
        if (known_bytes[0]) a_data_byte0: assert(PRDATA[7:0]   == expected_data[7:0]);
        if (known_bytes[1]) a_data_byte1: assert(PRDATA[15:8]  == expected_data[15:8]);
        if (known_bytes[2]) a_data_byte2: assert(PRDATA[23:16] == expected_data[23:16]);
        if (known_bytes[3]) a_data_byte3: assert(PRDATA[31:24] == expected_data[31:24]);
      end

      // --- Illegal Read Error Assertion ---
      // An invalid read is one where PWRITE=0 but PSTRB is not zero. This should
      // be flagged by the slave with PSLVERR on the following cycle.
      if (past_valid && $past(is_setup && !PWRITE && PSTRB != 4'b0)) begin
        // Requirement: An invalid read (PSTRB != 0) should be flagged with PSLVERR.
        a_illegal_read_slverr: assert(PSLVERR == 1'b1);
      end
    end
  end

  // --- Covers ---
  always @(posedge PCLK) begin
    if (past_valid) begin
        if (!past_PRESETn && PRESETn) begin
            c_reset_release: cover(1);
        end

        if (PRESETn) begin
            // Cover a full write, a partial write, and a zero-strobe write to the watched address
            if (write_complete && at_watched_addr) begin
                c_full_write:   cover(PSTRB == 4'b1111);
                c_partial_write:cover(PSTRB != 4'b1111 && PSTRB != 4'b0000);
                c_zero_strobe_write: cover(PSTRB == 4'b0000);
            end

            // Cover the data integrity assertion trigger for at least one known byte.
            if (read_complete && at_watched_addr && $past(saw_legal_read_setup_at_watched) && |known_bytes) begin
                c_read_after_write: cover(1);
            end

            // Cover the trigger for the illegal read check
            if (is_setup && !PWRITE && PSTRB != 4'b0) begin
                c_illegal_read_setup: cover(1);
            end
        end
    end
  end

endmodule
