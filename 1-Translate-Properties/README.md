# chia-translate-gcd

Property Set Conversion case study: porting a GCD (binary/Stein's algorithm)
core's formal-verification setup from the commercial OneSpin tool to the
open-source SymbiYosys (SBY) backend, via a CHIA agentic loop
(`translate-properties.py`).

## Given (original OneSpin reference)

| File | Description |
|---|---|
| `gcd_binary.sv` | The GCD core RTL under test (WIDTH-parametrized). |
| `run_onespin.tcl` | Original OneSpin flow script (Tcl) - kept for reference only. SBY cannot run it. |
| `fv_gcd_binary.sva` | Original OneSpin SVA property set: `reset_p`, `idle_p`, `gcd_p`, `wcl_p`. This is the authoritative spec the loop translates. |

## Generated by the CHIA loop (LLM-authored)

| File | Description |
|---|---|
| `fv_gcd_sby.sv` | SBY-compatible checker: reimplements the four properties above as immediate assertions, since SBY's native SVA subset doesn't support concurrent operators or `bind`. |
| `gcd.sby` | SymbiYosys job configuration (engines, depth, `[tasks]`). |

Both are written from scratch by `translate-properties.py`'s LLM loop and get
overwritten on every run where SBY reports an `ERROR`. They aren't meant to
be hand-maintained as the source of truth - if the translation is wrong, fix
the loop's prompts (`TRANSLATE_PROMPT`/`EXPLAIN_AND_FIX_PROMPT`) instead, so
the fix survives the next regeneration.

## Driver

| File | Description |
|---|---|
| `translate-properties.py` | The CHIA pipeline itself: runs SBY, and on translation error or genuine property violation asks an LLM to fix the checker/config or (rarely, for this Property Set Conversion experiment) the RTL, applying its proposed edits. |

## Setup

```bash
export VERTEX_PROJECT=your-gcp-project-id
```

## Usage

Run from **this directory** so its RTL/property files ship as part of the
job's `working_dir`. `--working-dir` is required and must be the absolute
path to this same directory on whatever machine you're running on -
`"$(pwd)"` from here is the simplest way to get it right:

```bash
chia job submit --working-dir . -- python translate-properties.py \
    --working-dir "$(pwd)"
```

Add `--llm opencode` to use OpenCode instead of the default Vertex/Gemini
backend (in which case `--vertex-project`/`$VERTEX_PROJECT` is unused).
Run `python translate-properties.py --help` for the full flag list.
